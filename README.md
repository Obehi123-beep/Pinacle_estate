# Pinacle Estate

Pinacle Estate is a responsive real-estate website built with HTML, CSS, JavaScript, and Bootstrap.

The project was created as part of my frontend development journey to practice building multi-page websites, responsive layouts, navigation, property listings, blog sections, and interactive real-estate pages.

## Features

* Responsive real-estate website
* Multi-page website structure
* Property listings and property details
* Property grid and listing pages
* Real-estate agent pages
* Blog and article sections
* About and Contact pages
* Property search and browsing interface
* Responsive navigation
* Mobile-friendly layouts
* Real-estate service sections
* Property and lifestyle content
* Responsive image galleries and visual content

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap
